## 六、已知坑（重构实测）

1. **并发会话冲突**：工作区选会话专属目录（任务/），勿与 workspace 下其他会话操作的目录重叠（本次并发会话把重构工作区 git 恢复过）
2. **坏 YAML 容错**：cordis.patch.yml 写非法 YAML 实例仍能启动（DSH 容错跳过），真实致崩类型 = 合法 YAML 引用缺失插件
3. **guardian 拉起**：多实例场景用 `DSH_START_CMD` 显式固定端口，避免 dsh-test-instance.sh 自动分配端口漂移
4. **自更新旧结构**：远端旧结构高版本号（1.x）不是误判——版本号更高是事实，但 majorUpgrade=true 表示不可自动更新
